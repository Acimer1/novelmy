# 番茄小说下载器 Web 版 — 实现文档

## 目标

在网页上输入小说链接或搜索书名，通过 `fanqie-desktop.exe` 下载小说，再将下载好的文件转发到网页供用户下载。

**核心原则：把 exe 当成中转站，不逆向签名逻辑。**

---

## 技术方案

```
浏览器  →  Flask(server.py)  →  CDP(WebSocket)  →  fanqie-desktop.exe(Tauri)  →  番茄API
   ↑                                                                            ↓
   ←←←←  web_downloads/  ←←←  sync_files()  ←←←  Downloads/FanqieNovels/  ←←←←←
```

### 为什么用 CDP？

`fanqie-desktop.exe` 是 Tauri 2 + Rust 程序，界面用 WebView2 渲染。Tauri 的所有业务命令都挂在前端的 `window.__TAURI__.core.invoke()` 上。

通过给 exe 注入 `--remote-debugging-port=9222` 启动参数，WebView2 会开放 Chrome DevTools Protocol，外部程序可以用 WebSocket 连接进去，执行 JavaScript，从而调用 Tauri 命令。

**这相当于拿到了 exe 全部能力的远程控制权，无需逆向。**

---

## 关键步骤

### 1. 启动 exe 并开启 DevTools

```python
env['WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS'] = '--remote-debugging-port=9222 --remote-allow-origins=*'
subprocess.Popen(str(EXE_PATH), env=env)
```

- `--remote-debugging-port=9222`：开启 CDP 调试端口
- `--remote-allow-origins=*`：允许任意来源连接（不加会 403）

### 2. 获取 CDP WebSocket 地址

```python
r = requests.get('http://127.0.0.1:9222/json/list')
ws_url = r.json()[0]['webSocketDebuggerUrl']
```

### 3. 通过 CDP 调用 Tauri 命令

这是整个方案的核心。通过 `Runtime.evaluate` 执行一段 JS，JS 内部调用 `window.__TAURI__.core.invoke('dispatch', { action, payload })`：

```python
def invoke_tauri(action, payload=None):
    ws = websocket.create_connection(ws_url, timeout=30)
    cmd = {
        'id': 1,
        'method': 'Runtime.evaluate',
        'params': {
            'expression': f'''
            (async () => {{
                const result = await window.__TAURI__.core.invoke('dispatch', {{
                    action: '{action}',
                    payload: {json.dumps(payload or {}, ensure_ascii=False)}
                }});
                return JSON.stringify(result);
            }})()
            ''',
            'awaitPromise': True,
            'returnByValue': True
        }
    }
    ws.send(json.dumps(cmd))
    result = json.loads(ws.recv())
    value = result['result']['result']['value']
    return json.loads(value) if isinstance(value, str) else value
```

**关键发现：所有命令统一通过 `dispatch` 入口调用，不能直接 invoke 命令名。**

### 5. 文件同步

exe 把文件下载到 `C:/Users/acimer/Downloads/FanqieNovels/`，同时把下载记录写到 `%APPDATA%/com.pofl.fanqienoveldownloader/rust_state.json`。

`sync_files()` 做两件事：
1. 读 `rust_state.json` 的 history，把 `file_exists=true` 的文件复制到 `web_downloads/`
2. 扫描下载目录，把大于 1KB 的 txt 也复制过来

```python
def sync_files():
    data = json.loads(CONFIG_FILE.read_text('utf-8'))
    for item in data.get('history', []):
        if item.get('file_exists'):
            src = Path(item['save_path'])
            if src.exists():
                dst = WEB_DIR / src.name
                if not dst.exists():
                    shutil.copy2(src, dst)
```

### 6. 下载流程

```
1. 前端 POST /api/download {url 或 book_id}
2. server 从 URL 提取 book_id（正则匹配 book_id=\d+ 或 /page/\d+）
3. invoke_tauri('book_detail', {book_id}) 获取书名作者
4. invoke_tauri('create_download', {...}) 创建任务，拿到 job_id
5. 返回 {job_id, book_name, status: 'queued'} 给前端
6. 前端每 2 秒轮询 GET /api/jobs
7. 找到对应 job，读 progress 和 status
8. status=done 时，调用 POST /api/sync 同步文件
9. 前端刷新文件列表，用户点"下载"获取 TXT
```

### 7. 前端界面

`web_static/index.html` 提供两个标签页：

- **链接下载**：粘贴链接 → 提取 book_id → 下载
- **搜索下载**：输入关键词 → 调 `/api/search` → 显示封面/书名/作者/简介 → 点"下载"

底部显示已下载文件列表，每项有"下载"按钮，点击通过 `/api/file/<book_name>` 下载 TXT。

## 踩过的坑

1. **CDP 403 错误**：必须加 `--remote-allow-origins=*`
2. **Command not found**：Tauri 命令不能直接 invoke，必须通过 `dispatch` 统一入口
3. **save_path 路径混用**：配置文件里有的用 `\\` 有的用 `/`，`Path()` 能正常处理
4. **文件名匹配**：前端下载时用 `book_name` 模糊匹配文件名（`if book_name in f.stem`）
5. **旧服务残留**：修改 server.py 后必须重启 Flask，否则跑的是旧代码
